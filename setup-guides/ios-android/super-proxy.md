# Super Proxy

## Configuring Super Proxy

Install Super Proxy from Google Play.

{% embed url="https://play.google.com/store/apps/details?id=com.scheler.superproxy" %}

## Creating a profile

Open the app and tap `Add proxy`.

<figure>
  <picture>
    <source srcset="../../.gitbook/assets/super-proxy-android-add-proxy_black.png" media="(prefers-color-scheme: dark)">
    <img src="../../.gitbook/assets/super-proxy-android-add-proxy_white.png" alt="Adding a proxy in Super Proxy">
  </picture>
</figure>

Enter a profile name in `Profile name`, select the protocol, and fill in `Server`, `Port`, `Username`, and `Password` using the details from your order's `Proxy List`. Then save the profile.

<figure>
  <picture>
    <source srcset="../../.gitbook/assets/super-proxy-android-proxy-form_black.png" media="(prefers-color-scheme: dark)">
    <img src="../../.gitbook/assets/super-proxy-android-proxy-form_white.png" alt="Proxy configuration in Super Proxy">
  </picture>
</figure>

{% hint style="info" %}
The data format and an example order are described in [Getting Started](../getting-started.md).
{% endhint %}

Select the profile you created and start the connection.

<figure>
  <picture>
    <source srcset="../../.gitbook/assets/super-proxy-android-start_black.png" media="(prefers-color-scheme: dark)">
    <img src="../../.gitbook/assets/super-proxy-android-start_white.png" alt="Starting the proxy in Super Proxy">
  </picture>
</figure>

The proxy is connected and ready to use in Super Proxy.
