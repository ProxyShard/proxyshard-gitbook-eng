Our official browser extension, <mark style="color:purple;">**ShardExtension**</mark>, can be installed in Opera directly from the **Chrome Web Store**.

## Installation

Open the extension page and click the install button. If Opera asks you to confirm installation from the Chrome Web Store, approve the request.
