# ShardExtension for Mozilla Firefox

Our official browser extension, <mark style="color:purple;">**ShardExtension**</mark>, lets you manage proxies directly in Mozilla Firefox. Install it from **Firefox Add-ons**.

{% embed url="https://addons.mozilla.org/en-US/firefox/addon/proxyshard-smart-proxy-manager/" %}

{% hint style="success" %}
The Mozilla Firefox version supports <mark style="color:purple;">**SOCKS5**</mark> through the extension.
{% endhint %}
