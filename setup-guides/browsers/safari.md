# Safari

Unfortunately, there is no working extension for the <mark style="color:purple;">Safari</mark> browser. It does not support add-ons with this functionality, but you can consider alternative options:\
1\) [Setup for MacOS](../macos/)\
2\) [Antidetect browsers](../antidetect-browsers/)\
3\) Install [Chrome](chrome/), [Mozilla Firefox](mozilla-firefox/), or another browser with extension support (Opera, Brave, Vivaldi ...)
